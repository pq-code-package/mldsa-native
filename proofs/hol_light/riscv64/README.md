# HOL Light proofs for the RISC-V 64 backend (in preparation)

This directory will hold the HOL Light proofs for the RISC-V 64 assembly in
[dev/riscv64/src](../../../dev/riscv64/src). No proofs exist yet.

## Status

- [mldsa/](mldsa) contains the assembly that the proofs will verify. It is
  generated by `scripts/autogen` from `dev/riscv64/src` using `scripts/simpasm`,
  in the same way as for [aarch64](../aarch64), [x86_64](../x86_64) and
  [riscv32](../riscv32).
- The assembly is built with `.option norvc` and `.option norelax`, so the byte
  code contains no compressed instructions and the linker cannot rewrite it.
  The object code verified by HOL Light is therefore exactly the code that is
  linked into the library.

## Prerequisite: an RV64 + RVV model in s2n-bignum

The [riscv32](../riscv32) proofs use the RV32IM model of
[s2n-bignum](https://github.com/awslabs/s2n-bignum).
The proofs here additionally need:

1. **RV64IM:** 64-bit registers and addresses, and the RV64-only instructions
   (`addiw` and similar). The base and M instructions used by the kernels are
   few.
2. **The vector extension (RVV 1.0):** the vector register file, the `vl`,
   `vtype` and `vxrm` state, `vsetvli`, and the vector instructions used by the
   kernels, including fixed-point (`vsmul`), widening (`vwmul`, `vwmacc`),
   narrowing (`vnsrl`, `vnsra`), strided (`vlse32`, `vsse32`) and permutation
   (`vrgatherei16`, `vcompress`) instructions. The model must reflect two kinds
   of freedom the specification gives to implementations:
   - For `VLMAX < AVL < 2*VLMAX`, `vsetvli` may return any `vl` in
     `[ceil(AVL/2), VLMAX]`.
   - With the tail-agnostic and mask-agnostic policies (`ta`, `ma`), inactive
     elements may be left unchanged or overwritten with all ones.

   Both should be modelled nondeterministically, so that a proof covers every
   conforming implementation.

`VLEN` should be a parameter of the model. Kernels written for a fixed `VLEN`
(NTT and inverse NTT, `VLEN=128` and `VLEN=256`) can then be proved for that
value, and the vector-length agnostic kernels for all `VLEN`.

## Planned specifications

The specifications follow the AArch64 ones in [aarch64/proofs](../aarch64/proofs)
and the contracts in
[arith_native_riscv64.h](../../../dev/riscv64/src/arith_native_riscv64.h). All
functions except the rejection samplers also need constant-time proofs; for
`rej_uniform_eta{2,4}`, only the positions of the accepted coefficients may
leak.

| Function | VLEN | Specification |
|----------|------|---------------|
| `ntt_vlen128_riscv64_asm`, `ntt_vlen256_riscv64_asm` | 128, 256 | For inputs bounded by q in absolute value, the output is congruent mod q to the NTT of the input, in bitreversed order, and bounded by 9q. |
| `intt_vlen128_riscv64_asm`, `intt_vlen256_riscv64_asm` | 128, 256 | For inputs bounded by q in absolute value, the output is congruent mod q to the inverse NTT of the input, times 2^32, and bounded by q. |
| `poly_pointwise_montgomery_riscv64_asm` | any | For inputs bounded by `MLD_NTT_BOUND`, each output coefficient is congruent mod q to the product of the input coefficients, times 2^-32, and bounded by q. |
| `polyvecl_pointwise_acc_montgomery_l{4,5,7}_riscv64_asm` | any | For `u` in [0, q) and `v` bounded by `MLD_NTT_BOUND`, the output is congruent mod q to the scalar product of `u` and `v`, times 2^-32, and bounded by q. |
| `poly_caddq_riscv64_asm` | any | Each output coefficient is the input coefficient plus q if negative. |
| `poly_chknorm_riscv64_asm` | any | Returns 0 if all coefficients are below `B` in absolute value, and 1 otherwise. |
| `poly_decompose_{32,88}_riscv64_asm` | any | As `mld_decompose()` in the C reference, coefficient by coefficient. |
| `poly_use_hint_{32,88}_riscv64_asm` | any | As `mld_use_hint()` in the C reference, coefficient by coefficient. |
| `polyz_unpack_{17,19}_riscv64_asm` | any | As `mld_polyz_unpack()` in the C reference. |
| `keccak_f1600_x1_zbb_riscv64_asm` | n/a (scalar, Zbb) | The state is replaced by the Keccak-f[1600] permutation of the input state. |
| `rej_uniform_riscv64_asm` | any | The output is the first `len` 23-bit values from `buf` that are below q; the function returns their number. No constant-time proof is needed (public data). |
| `rej_uniform_eta{2,4}_riscv64_asm` | any | As `mld_rej_eta()` in the C reference. |
