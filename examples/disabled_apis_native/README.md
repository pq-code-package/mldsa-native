# Disabled APIs (Native Backends)

Same as [disabled_apis](../disabled_apis), but with native arithmetic
and FIPS-202 backends enabled (`MLD_CONFIG_USE_NATIVE_BACKEND_ARITH`,
`MLD_CONFIG_USE_NATIVE_BACKEND_FIPS202`).

## Usage

```bash
make build   # Build all 12 variants
make run     # Run all 12 variants
```
