# FIPS202 backend for Armv8.1-M

This directory contains the source code for the Armv8.1-M FIPS202 backend. It
combines the direct MVE/Helium x4 sources from
[dev/fips202/armv81m/src](../../../../../dev/fips202/armv81m/src) with the
scalar x1 sources from
[dev/fips202/armv81m_opt/src](../../../../../dev/fips202/armv81m_opt/src),
whose permutation is generated by SLOTHY from
[dev/fips202/armv81m_clean/src](../../../../../dev/fips202/armv81m_clean/src).

**Warning:** This backend is still in active development and has not yet undergone
the same level of review as the rest of the code. Use at your own risk!
